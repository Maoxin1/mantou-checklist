## 主要变化

1. 页面和海报共用暖纸 `#fffaf1`、墨色 `#292824`、陶土 `#a84e32`，用浅叶与浅陶区分每日记录和本周进度
2. 直接复用博客的 01 SVG 字标与 P1 行走角色；Canvas 使用同一份矢量路径，并按原始比例绘制，不等待外部图片请求
3. 标题、正文、英文和数字使用 Noto Sans SC 优先的完整字体回退链，不加载预览用残缺子集或第三方远程字体；不同操作系统可能使用 PingFang SC / Microsoft YaHei / Noto Sans CJK SC
4. 桌面最大宽度 1080px，≤760px 单列并优先显示填写；边距、边框、圆角与博客统一，去除大阴影与绿色渐变
5. 手机默认进入填写视图；页签支持左右方向键、Home / End、roving tabindex 与面板聚焦；底部导出条保留安全区空间
6. 输入、按钮、页签和日记开关保持至少 48px 触控高度，阅读滑块增加明确可访问名称
7. 海报仍为 1080×1536；原阶段、今日、周统计、最多三个交付物均保留，调整卡片留白与字重
8. PWA 图标、启动底色同步；构建和 SW v28 缓存包含新 identity 资源

## 数据与兼容

`state.js`、`backup.js`、`config.json` 没有修改。原 localStorage 键、旧本地状态迁移、v1/v2 备份格式、日期边界、日记计数、Web Locks、多窗口冲突和保存失败保护全部保留。`app.js` 只新增视觉绘图导入及海报绘制改动。
