# mantou 博客视觉对齐与验收记录

日期：2026-10-04

这是该轮视觉改版的历史验收记录。2026-10-09 的名称与 P1 应用图标变更、SW v29 及尚待完成的浏览器检查，见 [PWA 品牌统一说明](pwa-branding.md)。

## 基线与范围

- 清单源版本：GitHub main `076c4131a17ebb8c0c82b8761587a8d3a1a2ebf5`，开始修改前逐文件校验 Git blob SHA
- 博客源版本：`03c40b91e49ea82e34c5be5681a970a0d2981dbd`
- 实际查看线上博客首页，并读取 2026-10-04 12:58 UTC 的视觉规范最新版
- 按已生效的 01 字标、P1、暖纸与墨色、陶土强调色对齐；最新漫画首页仍是候选，不将其当作已上线基线
- 本轮只做视觉、排版、触控、键盘访问与导出图片一致性；不增加字段，不建立账号或新数据服务

## 主要变化

1. 页面和海报共用暖纸 `#fffaf1`、墨色 `#292824`、陶土 `#a84e32`，用浅叶与浅陶区分每日记录和本周进度
2. 直接复用博客的 01 SVG 字标与 P1 行走角色；Canvas 使用同一份矢量路径，并按原始比例绘制，不等待外部图片请求
3. 标题、正文、英文和数字使用 Noto Sans SC 优先的完整字体回退链，不加载预览用残缺子集或第三方远程字体；不同操作系统可能使用 PingFang SC / Microsoft YaHei / Noto Sans CJK SC
4. 桌面最大宽度 1080px，≤760px 单列并优先显示填写；边距、边框、圆角与博客统一，去除大阴影与绿色渐变
5. 手机默认进入填写视图；页签支持左右方向键、Home / End、roving tabindex 与面板聚焦；底部导出条保留安全区空间
6. 输入、按钮、页签和日记开关保持至少 48px 触控高度，阅读滑块增加明确可访问名称
7. 海报仍为 1080×1536；原阶段、今日、周统计、最多三个交付物均保留，调整卡片留白与字重
8. 启动底色同步；构建和 SW v28 缓存包含新 identity 资源。当时的 PWA 图标仍是通用清单符号，尚未使用 P1；该缺口在后续品牌统一改动中处理。

## 数据与兼容

`state.js`、`backup.js`、`config.json` 没有修改。原 localStorage 键、旧本地状态迁移、v1/v2 备份格式、日期边界、日记计数、Web Locks、多窗口冲突和保存失败保护全部保留。`app.js` 只新增视觉绘图导入及海报绘制改动。

手机默认视图从预览改成填写是本轮唯一交互入口变化；依然可以一按切换预览或直接下载。

## 仍需注意与发布边界

- Chromium 手机模拟通过不等于 iOS Safari、Android 手机实机都验证；软键盘和系统安全区仍建议在实际手机发布前确认
- 完整字体通过系统后备提供，跨系统字形和字宽允许轻微差异；未增加远程字体请求
- 单独交付的 HTML 预览为独立演示数据和内存存储，不注册 SW，不改正式数据
- 首批海报 PNG 为同绘图参数的矢量样张，非浏览器截图；现在以 CI 真实截图与 PNG 为浏览器验收证据
- 现有 `docs/images/` 仍保留此前版本的截图，不与本次 CI 工件混淆
